🤖 Meet JARVIS — the AI assistant we built over the last 3 months.

As Computer Science students, our days are a mix of lectures, labs, quizzes, assignments
and a hundred little tasks. So we built our own JARVIS — a voice-controlled desktop
assistant that actually helps us get through the day. And the best part: we built the whole
thing collaboratively with an AI coding assistant, step by step.

Here's what JARVIS can do 👇

🗣️ Talk to it hands-free — it listens all the time and answers out loud in a natural voice.

📅 Keeps our schedule — "What do I have today?" → it tells us our lectures and quizzes, and
reminds us before each one. It even exports to the iPhone calendar with a day-before alarm
for quizzes, so the reminder reaches us even when the laptop is closed.

🖥️ Controls the laptop — "open Arduino", "close Discord", "what apps are open?" — it opens
and closes any installed program, by voice.

👁️ Computer vision — we point the webcam at a component and ask "what am I holding?" or
"how many objects am I holding?" and it recognizes the hardware (ESP32, Arduino Uno/Nano,
breadboards, sensors) and counts them. Perfect for our electronics labs.

📎 Solves assignments — we upload the assignment (PDF or image), it reads it, opens VS Code /
IntelliJ / Arduino IDE, and starts writing the solution code in front of us — then explains
it. We say "run it" and it runs the code and reads back the output. If there's an error, we
tell it, and it debugs with us.

🧠 And it has a real brain — ask it anything, give it a fact and it remembers it, and it
decides on its own which action to take.

The whole thing is open source. If you're curious how a project like this actually comes
together — the voice, the vision, the tool-use, the system control — the full code and a
demo video are on GitHub. Feel free to explore it, learn from it, and build your own. 🚀

👉 GitHub: https://github.com/abdelrahman77mohammad-ops/JARVIS

Built with: Python · Flask · Groq (LLM tool-use) · Google Gemini (vision) ·
Web Speech API · and a lot of late-night debugging.
